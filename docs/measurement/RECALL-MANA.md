`57d0df0633d12064602993f39fe6a5ee5f62524c`, patch
`patches/0054-recall-wait-mana-threshold.patch`).

## Defect

`borg_caution()`'s recall-wait branch tested `BI_CURSP < BI_CURSP / 4`, which is
never true for positive mana, so a caster with more than 60 max SP in danger while
Recall is pending never used a restore-mana potion or activation to buy time. The
correction compares with `BI_MAXSP / 4`. Behaviour-active only for such casters.
No survival claim.

## Layered interaction with patch 0053 (source156)

The source fixture was recorded on pristine code, where the excessive-danger flee
branch was inverted and skipped for ordinary Borgs. Since patch 0053 an ordinary
Borg in excessive danger logs "Fleeing (excessive danger)" and takes
"Desperate for Stairs" before it reaches the recall-wait line, so the UNCHANGED
fixture stays red on both builds. This is asserted, not hidden, and the original
red attempt is retained in `artifacts/rm157/scenarios/source-*`. The line is
still reachable in the product whenever the flee branch is skipped (Morgoth-ready,
a unique nearby, a vault, character level 50 or more, or already fleeing). The
adapted fixture changes exactly one source line, `borg.ready_morgoth = 0` to `1`
(a Morgoth-ready caster), and is generated by the verifier from the unchanged
evidence file (the replaced line must occur once).
